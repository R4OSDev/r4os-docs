R4CODE Build/Run 0.51.50
========================

0.51.50 verbindet die interne IDE R4CODE mit dem echten inside-R4OS-
Buildpfad fuer einfache C-Console-Projekte.

Ziel
----

Ein Entwickler kann in R4CODE ein `R4X C Terminal Hello`-Projekt anlegen, die
Quelle bearbeiten, Build klicken und danach das erzeugte `.R4X` starten.

Der Pfad ist:

  R4CODE.R4X
  -> C:\SOFTWARE\R4CODE\R4BUILD.R4X BUILD <Projekt.R4CP>
  -> R4CC-v1-Core
  -> R4PACK-Core
  -> <Projekt>\out\<Name>.R4X
  -> R4CODE Run startet genau dieses Artefakt

Build
-----

Der Build-Button ruft nicht mehr `PLAN`, sondern `BUILD` auf. R4CODE speichert
vorher eine geaenderte geladene Datei, damit eine bearbeitete `src\main.c`
wirklich die Quelle des erzeugten Programms ist.

Der Outputbereich zeigt das R4BUILD-Log. Darin muessen fuer einen erfolgreichen
C-Console-Build sichtbar sein:

  R4CC compile: OK
  R4PACK package: OK
  build result: OK

Run
---

Run berechnet den Artefaktpfad aus der geladenen `.R4CP`:

  Projektdatei-Verzeichnis + [Output] Artifact

R4CODE startet nur diesen Pfad ueber `R4SYS.programRun`. Es gibt keinen
Fallback auf ein installiertes Beispielprogramm und keinen Zugriff auf
Host-Tools.

Fehler
------

Eine fehlerhafte C-Datei laeuft durch denselben Buildpfad. R4BUILD schreibt die
R4CC-Diagnose in `C:\SOFTWARE\R4CODE\LOGS\R4BUILD.LOG`, und R4CODE zeigt das
Log im Outputbereich. Der Projektstatus wird auf `Build failed` gesetzt.

Abnahme
-------

Der automatische Smoke-Test ruft:

  C:\SOFTWARE\R4CODE\R4CODE.R4X /SELFTEST

Der Selftest:

1. schreibt ein Projekt nach `C:\TEMP\R4CODE\HELLOC`
2. schreibt eine geaenderte `src\main.c`
3. ruft R4BUILD mit `BUILD` auf
4. prueft `R4CC compile: OK` und `R4PACK package: OK`
5. startet `C:\TEMP\R4CODE\HELLOC\out\HELLOC.R4X`
6. prueft anschliessend eine kaputte C-Quelle auf sichtbare `R4CC error`-
   Diagnose

Die Test-AUTOEXEC startet das erzeugte Artefakt danach noch einmal direkt,
damit die Programmausgabe im Terminal-Log sichtbar ist.

Die erfolgreiche Programmausgabe lautet:

  HELLO from R4CODE edited source
