R4OS desktop icons
==================

R4OS uses the standard Windows ICO container with the `.ICO` extension.
There is no R4OS-specific icon format.

Icon sources
------------

Program-owned icons are stored as resources in the R4M0 container. External
or user-replaceable icons belong under `C:\R4OS\Media\Icons\`. Desktop
links may request an external path or use the target program's internal
resource. A missing or invalid icon falls back to a generic application or
folder icon.

The current decoder supports classic ICO directories and uncompressed DIB
entries used by the shipped 32-bit and selected paletted icons. PNG-compressed
ICO entries and the full set of legacy bitmap depths are not guaranteed.

Desktop layout is not stored in the icon or link. `.LNK` files describe the
target and title; `C:\R4OS\CONFIG\DESKLAY.R4S` owns positions.
