R4OS test image overlay
=======================

The Distribution Test profile overlays
`Repositories/Distribution/TestInjection/` on the normal `Injection/` tree.
It may add test-only configuration, fixtures and startup behavior without
changing the Slim or Full image.

Test-only modules use `IMAGE_SCOPE=test` or an explicit Test-profile include.
Production modules must not depend on files that exist only in the overlay.
The image planner rejects unknown scopes, duplicate targets and missing
artifacts.

The subsystem runtime acceptance explicitly includes the otherwise Full-only
AUDSVC artifact in the Test profile. This exercises the production app-audio
and service path without changing AUDSVC's normal scope or the Slim and Full
profile contents. Two BAS fixtures are resolved through the installed
subsystem catalog and run concurrently before AUTOEXEC emits the host and
runtime proof markers.

`Tools\Build.bat -test` builds the Test workspace, creates and verifies the
image, starts QEMU headless and evaluates the guest markers. The complete
test inventory is maintained in `Docs/Inventory/Tests.json`.

The existing guest marker gate also invokes the AUDSVC self-test. It proves
explicit mute, legacy volume compatibility, one common master fanout across
two materialized streams and safe persistence across a service restart. The
Desktop marker covers the built-in volume item's tray ordering, anchored
popup targets, perceptual gain mapping and bounded AUDSVC path. Both tests
restore the prior master state; no additional test gate is introduced.
