Independent Runtime-R4L libraries
=================================

R4STD, R4IMG and R4FONT are independent Runtime-R4Ls under
`Repositories/Libraries/`. Each library unit owns:

```text
Contract/   schema and compatibility baseline
Bindings/   Zig and C clients
Source/     provider implementation
Tests/      contract, conformance and runtime tests
module.R4MF and build files
```

A consumer imports `<MODULE>:<TABLE>:<MINIMUM_REVISION>`. The generic loader
resolves module and export names case-insensitively and supplies the provider
pointer in R4XStart. The library binding validates identity, API major,
revision, table size and required slots.

Compatible implementation changes and append-only table revisions remain
inside the library repository. They do not require a Kernel, central Contract
or core SDK change. Consumers change only when they use new slots or move to
an incompatible API major.

Loaded code remains valid for its lifetime. An update publishes a new
artifact atomically for a safe activation point; it does not replace code
beneath active function pointers.
